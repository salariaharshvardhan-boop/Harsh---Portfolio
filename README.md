# Harshvardhan 3D Creator Portfolio

A modern portfolio website for a 3D creator and visual designer, built with React, Vite, and Framer Motion.

## Features

- Premium dark portfolio aesthetic
- Sticky project cards with cinematic layout
- About, services, projects, and contact sections
- Responsive design for desktop and mobile
- Smooth motion effects and animated transitions

## Run locally

Prerequisites:
- Node.js 18+

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal, usually:
   ```bash
   http://localhost:5173
   ```

## Build for production

```bash
npm run build
```

## Notes

- Do not commit `node_modules`
- Do not commit `.env` files
- This project is ready to drag into GitHub as a clean frontend portfolio repository
